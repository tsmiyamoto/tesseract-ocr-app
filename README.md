# Tesseract OCR App

Tesseract.js を使って日本語の画像・PDFドキュメントからテキストを抽出するシンプルなブラウザアプリです。すべての処理がブラウザ内で完結するため、ファイルがサーバーに送信されることはありません。

## 必要環境

- モダンなウェブブラウザ（最新の Chrome / Edge / Firefox / Safari など）
- インターネット接続（CDN から Tesseract.js と PDF.js のスクリプトを読み込むため）

## 使い方

1. リポジトリをクローンし、`index.html` をブラウザで開きます。
   - もしくは、任意の静的サーバーで公開してください（例: `npx serve .`）。
2. 画面上部の「ファイルを選択」ボタンから日本語の画像または PDF ファイルをアップロードします。
3. 解析が完了すると、ページ下部にテキストが表示されます。
   - PDF の場合はページごとに OCR を実行し、結果がページ単位で表示されます。
4. 「リセット」ボタンで入力と結果をクリアできます。

## 注意事項

- 初回の解析時に日本語の学習データをダウンロードするため、数十 MB の通信が発生します。
- Tesseract.js と PDF.js は CDN から読み込んでいるため、オフライン環境で利用する場合はそれぞれのスクリプトをダウンロードしてローカルに配置してください。
- PDF の描画には `pdf.js` を利用しており、解像度を上げるために 2 倍スケールで画像化しています。大きなファイルでは処理に時間がかかる場合があります。
